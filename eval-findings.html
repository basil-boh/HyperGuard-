02Is the risk score smarter than a dumb rule?

Six scorers, same cases, same operating point — the shipped 0.58, not a tuned one, because tuning after the fact is how evaluations lie.

The deployment blocker

The restraint story is half true. HyperGuard never bothers the grocery run — 0 of 65 ordinary transfers flagged. But 80.2% of legitimate large transfers to a new payee get intercepted. An 81-year-old paying a renovation contractor gets the same phone call as a scam victim.

03Does the classifier survive rewording?

The Educator matches literal substrings. This asks what happens when the same scam is described as "an account where it'll be protected" rather than "safe account".

The quieter number is worse

The matcher correctly says "no scam" for only 72.6% of legitimate customers. It is calling roughly one in four innocent people a scam victim, on the phone, by name.

Do not quote the LLM's 100%

The same model that generated the test utterances also classified them — it is grading its own handwriting. The comparison stands, since the keyword matcher had no such advantage, but the absolute figure will not survive real transcripts. Regenerating with a different model family is the fix.

06What these numbers are not

Stated before anyone asks, because the limits are as informative as the results.

The dataset is synthetic

Transfer features come from distributions written by hand; utterances are LLM-generated from plain-language scam briefs. These results describe how the system behaves on the world the generator imagines. If those assumptions are wrong, every number here is wrong in the same direction and confidently so.

What fixes it: sourced cases from SPF scam briefs and ScamShield advisories, labelled by two annotators with inter-rater agreement reported.

But it did escape the circularity, and that is measured

The shipped fixtures were unusable for evaluation — the victim scripts and the classifier's keyword lists live in the same file, so the test data was written from the answer key. The replacement never sees those lists. Similarity to the old fixtures is 0.12. The circularity is quantified rather than assumed.

Four questions no dataset here can answer

Whether real scams resemble these six archetypes. Whether it works in Mandarin, Hokkien, Malay or Tamil — the languages the target users would actually panic in. Whether it survives the scammer still being on the other line, coaching the victim through the call. And whether a frightened 72-year-old mid-manipulation actually listens — that needs people, not test cases.

1,011 tests pass. 914 are property tests asserting invariants over generated inputs — score bounds, determinism, monotonicity, every signal carrying a readable reason. Three are deliberately failing tests pinning the open bugs above, so fixing one forces the fix to be locked in rather than quietly forgotten.
